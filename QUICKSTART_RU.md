# Запуск AGMEN как приложения

## На этом компьютере

Откройте `RUN_AGMEN.cmd` двойным щелчком. Он запустит локальный сервер и откроет приложение по адресу **http://127.0.0.1:7860**. Для остановки есть `STOP_AGMEN.cmd`. В родительской папке также есть короткий `AGMEN.cmd`.

## Из самостоятельного ZIP

1. Распакуйте `AGMEN-Windows-Local.zip` в папку с правом записи.
2. Установите Python 3.12 с python.org, если его нет.
3. Откройте `RUN_AGMEN.cmd`. Первый запуск устанавливает CPU-зависимости в `.venv`, требует интернет и может занять несколько минут. Node.js не нужен: интерфейс уже собран.
4. Следующие запуски работают без интернета. Миссии, модели и EDGE-журналы сохраняются в `data/` этой папки.

Это локальное браузерное приложение, а не отдельный `.exe`. Браузер — интерфейс; расчёты и обучение выполняются на вашем компьютере.

## Первая миссия

В Mission Control задайте число аппаратов, сценарий и контроллер. Запустите расчёт, затем воспроизведение. Можно включать плотность, траектории и векторы, выбрать аппарат, просмотреть аналитику и экспорт. Basic скрывает расширенные настройки, Professional открывает их.

В AI Laboratory можно начать обучение или дообучение, остановить/возобновить run и выбрать проверенный checkpoint. Низкий train loss сам по себе не гарантирует хорошую миссию. Встроенные веса имеют исходную историю пяти эпох, без исходных held-out результатов.

AGMEN EDGE: создайте пакет для аппарата из рассчитанной миссии, загрузите в виртуальное устройство и выполните локальные шаги. Отдельно отключайте интернет и радиоканал; восстановите радио и синхронизируйте журнал. Независимый CLI исполнителя описан в `AGMEN_EDGE.md`.

## Если приложение не открывается

Проверьте `logs/agmen-server.log`. Порт 7860 может быть занят другим приложением; задайте другой свободный `PORT` в `.env`. При первом запуске нужен доступ к PyPI и CPU-индексу PyTorch. При недоступности интернета используйте уже установленную `.venv` или подготовьте wheelhouse на совместимом компьютере.

Для работы в терминале с видимыми логами: `RUN_AGMEN.cmd --foreground`. Остановка — Ctrl+C. Сервер по умолчанию доступен только на этом компьютере. Географическая карта, реальные радиоданные и физические команды в новом приложении не подключены.
