# AGMEN: демо для жюри

Ссылка для телефона: **https://agmen-petr234512.msk1.amvera.tech/demo/**

Жюри сканирует QR и сразу получает готовые параметры: 12 аппаратов, математический контроллер, 80 минимальных шагов. Нажмите **Рассчитать миссию**, затем воспроизведите траектории. Можно менять число аппаратов и сценарий, загружать карту, рисовать запреты, запускать следующий этап после прибытия, скачивать результат и пробовать виртуальный EDGE. Регистрация и ввод API-ключа не требуются.

## QR для презентации

- `artifacts/jury/AGMEN-jury-card.png` — готовая карточка с подписью для слайда или печати.
- `artifacts/jury/AGMEN-demo-QR.png` — QR без подписей, на белом фоне.
- `artifacts/jury/AGMEN-demo-QR.svg` — масштабируемый QR.
- `artifacts/jury/demo-url.txt` — точный адрес, закодированный в QR.

QR содержит только публичную HTTPS-ссылку на `/demo/`, без токенов и секретов. Два PNG проверены независимым декодером ZXing. Не обрезайте белое поле вокруг QR при добавлении на слайд.

Повторная генерация при смене домена (нужны Pillow и reportlab; это вспомогательные инструменты, а не зависимости сервера):

```powershell
python scripts/build_jury_qr.py --url https://YOUR_DOMAIN/demo/
```

## Разделение с основным кабинетом

Обычный адрес `/` и API `/api/*` сохраняют текущий профиль и авторизацию. В режиме `private` рабочий кабинет по-прежнему требует ключ.

Демо обслуживается отдельным публичным приложением на `/demo/` и API `/demo/api/*`. Его миссии, карты и EDGE находятся в отдельном каталоге `data/demo` (в Amvera — `/data/demo`). Рабочие миссии, карты, обученные модели и журналы в демо не доступны. Браузер использует отдельные ключи `agmen-demo-*`, не читает и не отправляет рабочий API-токен.

Для демо действуют публичные ограничения: до 100 аппаратов и 150 минимальных шагов, вычислительный отрезок до 600 шагов с учётом внутреннего бюджета симулятора. Предзагруженная нейросеть доступна, обучение и приватные модели — нет. Основное приложение и демо используют общую ограниченную очередь; параллельный доступ не создаёт дополнительные вычислительные worker.

Демоархив общий для посетителей, предназначен для демонстрационных данных. Новому посетителю автоматически не открываются чужие расчёты; собственная последняя демомиссия восстанавливается в том же браузере. Хранилище расчётов ограничено; завершённые старые демозаписи ротируются при заполнении, с сохранением родителей нового этапа и активных задач.

## Обновление Amvera

После получения этого изменения связанной веткой Amvera должна собрать новый контейнер. Отдельно переключать основной профиль с `private` на `public` или вставлять ключ в ссылку не нужно.

Проверка без ключа:

```powershell
curl.exe https://agmen-petr234512.msk1.amvera.tech/demo/api/health
curl.exe https://agmen-petr234512.msk1.amvera.tech/demo/api/bootstrap
```

Оба запроса должны вернуть HTTP 200; профиль демо — `public`, `token_required=false`, `training_allowed=false`. При основном профиле `private` запрос `/api/bootstrap` без ключа должен по-прежнему возвращать HTTP 401.
