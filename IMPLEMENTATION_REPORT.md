# AGMEN + EDGE: отчёт о реализации

21 октября 2026. Результат — работающее локальное браузерное исследовательское приложение и самостоятельный автономный симуляционный исполнитель. Полная аппаратная production-квалификация из исходного ТЗ не заявляется.

## Реализовано

| Область | Фактический результат |
|---|---|
| Интерфейс | React/TypeScript, Mission Control, Basic/Professional, новая тёплая светлая/графитовая тёмная палитра с оливковым и терракотовым акцентами, сохранение темы, responsive, рисование зон, маркеры/траектории/плотность/поле, выбор аппаратов, журнал |
| Соединение | Same-origin API, ограниченные таймауты и повтор GET, проверка health, явное состояние потери связи и автоматическое восстановление с сохранением черновика; POST автоматически не повторяется |
| Своя территория | Локальная загрузка PNG/JPEG/WEBP до 4 МиБ, калибровка ширины/высоты в метрах, сохранённые подложки, эвристики dark/water/contrast с ручным подтверждением, запреты rectangle/circle/polygon и сохранение черновика |
| Backend | FastAPI, Pydantic, same-origin/Host guards, token private-профиля, health, ограниченная очередь, сохранение и восстановление |
| Математика | Исходные PDE, DCT/Пуассон, потоковый baseline и fleet-controller сохранены; новые миссии используют их функции |
| Контроллеры | Baseline, исходная U-Net и гибрид; выбор сохранённой проверенной модели. Нет молчаливой замены модели baseline |
| Симуляция | Реальная пошаговая интеграция отдельных виртуальных аппаратов до 500, шесть сценариев, пользовательские цели, препятствия, отказ/потеря радио/изменение цели |
| Воспроизведение | Пауза/продолжение/сброс, скорость и перемотка рассчитанных кадров. Это воспроизведение завершённого расчёта; пауза не останавливает выполняющееся фоновое вычисление |
| AI Laboratory | Отдельный CPU worker, train/validation/test, AdamW/Adam/SGD, параметры эпох/LR/batch/dataset, checkpoint, stop/resume, дообучение, графики/логи/история и test-метрики |
| Оптимизация baseline | Bounded grid search исходного `slot_gain` с сохранением результатов и лучшего значения; фиксированный исследовательский сценарий, objective final MAE |
| Аналитика | Измеренные MAE/TV/дистанция/нарушения/compute time, сравнения контроллеров и числа аппаратов, convergence nullable, JSON/CSV/PNG/SVG/PDF |
| EDGE builder | Versioned JSON-only ZIP, карта/назначение/лимиты/поля/опциональные веса, SHA256, лимиты размеров, безопасная валидация |
| EDGE runtime | Самостоятельный CLI без сервера, локальные вычисления baseline/neural/hybrid, state/journal, восстановление, независимые интернет/ground/peer/GNSS, hold/return/continue |
| EDGE sync | Отдельная копия реально переданных модельных journal/history в Ground Station, дедупликация, квитанция, экспорт, замороженная last-known телеметрия и отдельный dead-reckoning forecast |
| Поставка | Windows RUN/STOP, Linux launcher, собранная статика, ZIP builder, pinned constraints, Docker и Docker.Edge, CI, документация Amvera |

Территории сохраняются в `data/maps/`, выбранная карта и черновик запретов — в localStorage браузера; рассчитанная миссия фиксирует `map_snapshot`, размеры и подтверждённые зоны. Более поздняя калибровка подложки не меняет снимок старой миссии. Анализ только предлагает области по цвету и контрасту, без утверждения о распознавании объектов; неподтверждённые предложения не попадают в маску движения.

Подтверждённые прямоугольники, физические круги и многоугольники консервативно покрываются сеткой 24×24 и прямоугольными границами ячеек. Симулятор и EDGE проверяют весь отрезок каждого шага, включая переход через тонкую область с обеими конечными точками снаружи. Цель в запретной ячейке отклоняется до постановки расчёта в очередь; автоматически создаваемые заблокированные слоты переносятся в свободные ячейки с учётом в `restriction_policy`. EDGE хранит размеры, идентификатор и снимок метаданных территории, фигуры и рассчитанную маску; сам PNG в архив не включается.

## Что проверено локально

- Создано чистое `.venv-clean` Python 3.12, установлены `requirements-dev.txt`; `pip check` не обнаружил несовместимых зависимостей. Рабочая `.venv` тоже изолирована от системных пакетов, `pip check` проходит.
- **49 тестов прошли итоговым полным прогоном**, включая API, математику, обучение, EDGE, launcher и территории. Есть предупреждение Starlette об устаревании httpx TestClient API; ошибок тестов нет.
- Оригинальные регрессии дополнены проверками массы/неотрицательности/препятствий, реальной API-интеграции, очереди/профилей/восстановления/экспортов, обучения и EDGE.
- Обучение действительно запускалось в subprocess: stop/resume, реальные эпохи, сохранение модели и held-out test. Проверен локальный inference neural/hybrid, включая веса, переданные JSON-пакетом EDGE.
- В тестах EDGE запрещены socket connect, connect_ex, create_connection и DNS; независимый CLI проходит загрузку, исполнение и восстановление состояния. При отключении только интернета одинаковый предзагруженный независимый план даёт точно одинаковые позиции и метрики.
- Проверены потеря наземного/peer-радио, истечение свежести peer-наблюдений, политики hold/return/continue, потеря навигации, низкая батарея, повреждённый/неполный пакет, перезапуск и отдельная наземная квитанция.
- Production frontend проходит `tsc -b && vite build`.
- Финальная проверка тем: 20 экранов (5 разделов × 2 темы × desktop/mobile), 2400 измерений текста и 102 функциональных значка; нарушений контраста, ошибок JavaScript и горизонтального переполнения нет. Минимальный проверенный контраст текста 4.721:1, значков 4.91:1. Сохранение тёмной темы после перезагрузки проверено отдельно. Подписи запретов имеют светлый контур, элементы поверх подложки — непрозрачный фон.
- Дополнительный браузерный research-flow прошёл полностью: обучение 1 эпоха / 16 примеров (validation loss 0.0802391097), выбор полученной модели через UI, нейросетевая миссия 10 аппаратов / 21 кадр, затем три вычисленных варианта оптимизации baseline. Ошибок JavaScript/API нет. Эти малые данные проверяют интеграцию, не качество обученной модели.
- Последний Playwright smoke против настоящего сервера: создание миссии **5 аппаратов / 21 кадр**, четыре раздела, desktop/mobile, ноль ошибок JavaScript/API. Созданы пакет и устройство EDGE, выполнены локальные сегменты, OFFLINE и LINK LOST, проверена неизменность last-confirmed telemetry при отсутствии радио и ground journal после sync. Более ранний прогон также проверил 48 аппаратов / 121 кадр.
- Отдельно проверены все три контроллера на одинаковом seed и 10 аппаратах. Нейросеть действительно использует исходные веса; результаты различаются. Короткий прогон не достиг порога сходимости, что отражается как `null`.
- Прогон 500 аппаратов / 20 шагов завершился примерно за 4.16 с. При плотной расстановке и требовании дистанции 1.5 м зафиксированы нарушения: эта модель не гарантирует безопасное разделение группы.
- Launcher реально запускает сервер, STOP останавливает только относящиеся к нему процессы, повторный запуск восстанавливает миссии. Адрес на данном компьютере: http://127.0.0.1:7860.
- При диагностике `Failed to fetch` сервер на 7860 отсутствовал. Launcher теперь отделяет фоновый сервер от Windows terminal/job; два теста проверяют сохранение дочернего процесса после завершения launcher. Изолированный браузерный сценарий остановил и запустил отдельный сервер: состояние связи восстановилось, несохранённые имя/сценарий и результат с 5 аппаратами сохранились. Проверены таймаут, GET retry, отсутствие автоматического POST retry, авторизация скачивания и ошибки 401/403/422; исключений JavaScript нет.
- Устранена обнаруженная Windows sharing-lock гонка чтения состояния обучения во время атомарной замены `run.json`; временная блокировка повторяется ограниченно, повреждённый файл сохраняется и возвращает явную ошибку. Пройдены регрессии блокировки/повреждения и реальное stop/resume обучения.
- Обновлённый ZIP распакован в отдельный каталог и запущен на другом порту: загрузка карты 120×90 м, 5 аппаратов / 21 кадр и скачанный EDGE с подтверждённой геометрией прошли проверку. Пользовательские данные и окружения в архив не включены.
- Для территории добавлены 11 backend-проверок: повреждённые/несоответствующие MIME/слишком большие изображения, загрузка поверх прежнего лимита 256 КБ, сохранение и перезапуск, направление осей изображения, ручная калибровка, необязательность предложений, растеризация круга/многоугольника, запрет полных отрезков движения и передача территории в EDGE. Старые API, EDGE runtime и математические регрессии также прошли отдельными прогонами.
- Реальный браузерный сценарий `frontend/scripts/qa-territory.mjs` прошёл загрузку PNG, анализ dark/water, подтверждение кандидата, рисование трёх видов запретов, отмену/удаление, восстановление черновика, два расчёта и проверку скачанного EDGE-архива. Проверено, что недопустимый масштаб 9 м и ещё не применённые размеры не меняют геометрию. Архивная миссия сохранила 120×90 м после перекалибровки карты и перезагрузки; новый расчёт и EDGE-пакет получили актуальные 160×90 м, 4 зоны и 31 заблокированную ячейку. В первой миссии проверен 21 кадр. Выбор обеих тем сохраняется после перезагрузки, ошибок JavaScript/API нет, ширина документа на mobile совпала с viewport 390 px в обеих темах.

Воспроизводимые примеры: `examples/edge/mission-continue.zip`, `mission-hold.zip`, `mission-return.zip`. `comparison.json` содержит измеренные ONLINE/OFFLINE/LINK_LOST результаты, а не заданные заранее числа. В примере на шаге 80 endpoint совпал у всех трёх режимов для policy continue; при радиообрыве последняя подтверждённая телеметрия осталась на шаге 20. Progress proxy около 94% не равен завершённому заданию: `task_completion_fraction` в этом коротком прогоне равен 0.

Локальные скриншоты и машинные протоколы UI (`browser-smoke.json`, `research-browser-qa.json`, `territory-qa/territory-browser-qa.json`) находятся в `test-results/`; пользовательские тестовые миссии — в `data/`. Эти каталоги исключены из репозитория и ZIP. Команды повторения: `npm --prefix frontend run test:smoke`, `npm --prefix frontend run test:research` и из папки `frontend` — `node scripts/qa-territory.mjs` при запущенном локальном сервере; для Linux предварительно установить Chromium через Playwright. Для другого адреса теста территории задайте `AGMEN_URL`.

## Оставшиеся ограничения

1. Карта — локальное поле с задаваемыми размерами (по умолчанию 80×60 м) и необязательной PNG/JPEG/WEBP-подложкой. Нет проверенной географической привязки, GeoTIFF, offline geographic tiles, реального GNSS или сенсорной карты. Анализ изображения эвристический и требует подтверждения. Сетка 24×24 расширяет запреты до границ затронутых ячеек и может исключить узкие проходы; достижимость цели не гарантируется.
2. Упрощённая 2D-кинематика, постоянная высота, условные радио/батарея. Не реализована полнофизическая аэродинамика, оценка аппаратной надёжности и расхода энергии.
3. EDGE фиксирует начальное назначение и поле пакета. Будущие изменения целей движущегося сценария нужно переупаковывать; самостоятельное исполнение полного динамического плана не заявляется.
4. Peer-канал передаёт явно доступные модельные наблюдения, но реального радио-транспорта, сетевого discovery и аппаратной доставки пакетов пока нет. Веб-синхронизация виртуальная; отдельный CLI работает без неё.
5. SHA256 — целостность, не подпись. Для борта нужны доверенная подпись, управление ключами, защищённое обновление и независимый watchdog.
6. No-neighbor independent mode не гарантирует отсутствие столкновений. Отсутствие нарушений в отдельных тестах не переносится на неизвестные конфигурации.
7. Учётные записи/роли/MFA, общая транзакционная БД, внешняя очередь и несколько реплик не реализованы. Private использует токен; public имеет общее хранилище демонстрационных результатов.
8. Конфигурация архитектуры U-Net через UI, произвольные доли train/validation/test, выбор других функций оптимизации и распределённый training-worker не реализованы. Существующая архитектура и независимые фиксированные split сохранены.
9. Локальные RSS-лимиты кооперативные; жёсткие CPU/RAM устанавливаются контейнером/cgroups. Нельзя обещать жёсткую изоляцию обычного Windows subprocess.
10. Docker daemon на этом компьютере недоступен, поэтому контейнерные сборки/ARM-образы здесь не запускались. Подготовлен CI с Docker build; его удалённый результат проверяется отдельно после публикации.
11. Нет Raspberry Pi, Jetson, PX4/ArduPilot SITL и физических БПЛА в среде проверки. Сохранены MAVLink-модули и подготовлена инструкция; реальные испытания не выполнялись.
12. Нет доступа к кабинету Amvera. Руководство сверено с официальной документацией; создание проекта, настройка домена/секретов/хранилища и получение публичной HTTPS-ссылки остаются владельцу. Доступность Amvera не требуется EDGE CLI.

## Перед аппаратными испытаниями

Сначала воспроизвести всё в изолированном SITL, проверить координаты/время/setpoints, геозону и навигацию, остановку/RTL при радио/GNSS/батарее, подписи пакетов, аппаратные пределы и независимый kill/watchdog. После этого возможна отдельная квалификация на реальном устройстве. Новый AGMEN не предоставляет физических команд; public-деплой не способен автоматически начать аппаратную миссию.
