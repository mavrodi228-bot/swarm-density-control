# AGMEN · Mission Control + EDGE

Локальная исследовательская платформа управления плотностью виртуального роя. React + TypeScript, FastAPI, исходные PDE/Пуассон и SwarmUNet. Работает без обязательного облака; новый интерфейс обслуживает только симуляцию.

## Рабочее приложение в Windows

Двойной щелчок **RUN_AGMEN.cmd** → **http://127.0.0.1:7860**. Для остановки — **STOP_AGMEN.cmd**. На этом компьютере окружение устанавливается в ходе разработки. Для другого компьютера: Python 3.12, первый запуск скачивает CPU-зависимости; последующие запускаются офлайн. Собранный интерфейс включается в локальный ZIP. Node.js нужен только при изменении frontend.

Подробно: [QUICKSTART_RU.md](QUICKSTART_RU.md).

## Возможности

- Basic/Professional, тёмная и светлая темы, локальное поле с задаваемыми размерами в метрах (по умолчанию 80×60 м), целевые зоны, выбор аппарата и визуальные слои.
- Своя территория: PNG/JPEG/WEBP до 4 МиБ, ручные запреты прямоугольником, кругом и многоугольником. Анализ тёмных областей, водного цвета и контраста предлагает кандидатов; каждый запрет подтверждает оператор.
- **Очистить зоны** оставляет подложку и масштаб; **Новая карта** открывает чистое поле 80×60 м. Сохранённые карты, миссии и EDGE-пакеты остаются в архиве.
- Расчёт до фактического прибытия всей группы, воспроизведение, три контроллера, сценарии распределения/кластеров/патруля/обследования/сканирования/возврата, отказы и потеря радиосвязи в модели.
- Следующий этап на отдельной подробной карте: распределение, патрулирование, обследование или сканирование. Начало участка задаётся в метрах первой карты; позиции, скорости, заряд, идентификаторы аппаратов и исходные запреты сохраняются.
- Реальные измеренные метрики, сравнения и grid search исходного математического контроллера, JSON/CSV/PNG/SVG/PDF.
- AI Laboratory: отдельный процесс обучения, дообучение, checkpoint, остановка/возобновление, train/validation/test и история запусков.
- AGMEN EDGE: автономный пакет, строгая проверка целостности, локальный исполняемый модуль и журнал; независимые состояния интернета, наземного радио, peer-радио и навигации. [AGMEN_EDGE.md](AGMEN_EDGE.md).
- Данные и состояния сохраняются локально. Режим public ограничивает ресурсы и выключает обучение; private использует секретный токен.

Показываемые положение, заряд, связь и высота относятся к симуляции. Базовая модель не эквивалентна реальному полёту. Сходящиеся синтетические метрики не являются сертификацией нейросети.

В поле миссии нажмите **Загрузить карту**, задайте ширину и высоту участка и примените масштаб. Подложка сохраняется на сервере, черновик карты и запретов — в браузере; рассчитанная миссия фиксирует снимок карты, масштаба и подтверждённых зон. Последующая калибровка карты не меняет старые результаты. Запреты участвуют в расчёте и EDGE через консервативную сетку 24×24 с проверкой всего отрезка движения. Изображение само по себе не задаёт географическую привязку.

Ожидание прибытия включено по умолчанию. Число шагов задаёт минимальный горизонт с шагом **0,2 с**, а не момент принудительного завершения. После него движущиеся цели фиксируются, и группа продолжает физическое движение в назначенные области. MAE описывает плотность и не заменяет проверку прибытия каждого аппарата.

Один расчёт ограничен бюджетом до 1200 шагов в local/private и до 600 в public; для больших групп внутренний предел может быть ниже. Исчерпание бюджета оставляет миссию незавершённой. **Продолжить до цели** создаёт следующий вычислительный отрезок из последнего сохранённого состояния с теми же назначениями; история предыдущего отрезка сохраняется. Следующий сценарий доступен после прибытия всей группы. Недостижимая цель, отказ или потеря связи не считаются успешным прибытием.

## Разработка

```powershell
py -3.12 -m venv .venv
.venv\Scripts\python -m pip install -r requirements-dev.txt
npm.cmd --prefix frontend ci
npm.cmd --prefix frontend run build
.venv\Scripts\python -m pytest -q
.venv\Scripts\python launch_agmen.py --foreground
```

Vite dev: `npm.cmd --prefix frontend run dev`; отдельно `python -m uvicorn agmen_api:app --host 127.0.0.1 --port 8000`. В production API и статика работают на одном порту 7860.

Linux x86_64: Python 3.12, `sh run_local.sh --foreground`. Для ARM/Jetson используйте платформенные инструкции EDGE и подходящую сборку PyTorch.

## Docker

```sh
docker build -t agmen:local .
docker run --rm --name agmen --cpus=2 --memory=2g -p 7860:7860 -v agmen-data:/data agmen:local
```

Образ по умолчанию запускает public-профиль. Для приватного профиля задайте `AGMEN_PROFILE=private` и секрет `AGMEN_API_TOKEN` длиной от 24 символов. Для внешнего домена задайте `AGMEN_ALLOWED_HOSTS` и `AGMEN_ALLOWED_ORIGINS=https://ВАШ_ДОМЕН`. Одна реплика и один uvicorn worker: файловое хранилище не рассчитано на распределённую запись. [AMVERA_DEPLOYMENT_GUIDE.md](AMVERA_DEPLOYMENT_GUIDE.md).
