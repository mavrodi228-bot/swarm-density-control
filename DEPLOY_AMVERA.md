# Деплой Swarm Density Control GCS на Amvera

1. Создайте в Amvera новое приложение Python/Pip.
2. Загрузите содержимое этой папки в репозиторий приложения (важно: app.py и amvera.yml должны быть в корне).
3. Запустите сборку. Конфигурация уже задаёт `python app.py` и порт `7860`.
4. После успешного запуска откройте настройки приложения и добавьте бесплатный HTTPS-домен Amvera.
5. Проверьте публичный URL с телефона через мобильный интернет.
6. Переменную `SWARM_ENABLE_REAL` на публичном конкурсном сервере НЕ задавайте: реальные ARM/TAKEOFF-команды останутся заблокированы.
7. После получения окончательного HTTPS URL сделайте QR-код именно на этот URL.

Примечание: приложение изменено для прослушивания `0.0.0.0` и переменной `PORT`, что требуется для облачного хостинга.
